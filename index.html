PROJECT INFORMATION

Hospital Patient Registration System

An academic mini project for registering and managing basic patient information.

HTMLPage structure
CSSDesign and layout
JavaScriptForm and page actions
Vercel FunctionsServer-side API
Supabase PostgreSQLOnline SQL database

Main features

  • Register a patient with required details
  • Automatically generate a patient ID
  • View and search patient records
  • Edit existing patient information
  • Delete a record after confirmation
  • Store records in Supabase PostgreSQL
For college demonstration only

Use sample data only. This educational project does not include hospital-grade security or user authentication.
